Privacy Policy

GitHub Actions Workflow Tree — Last updated: April 12, 2026

Overview

GitHub Actions Workflow Tree is a Chrome browser extension that organises the GitHub Actions workflow sidebar into a collapsible, grouped tree. This policy explains what data the extension handles and how.

Data we collect

We collect no personal data. The extension does not transmit any information to external servers, analytics services, or third parties of any kind.

Data stored locally

The extension stores the following data exclusively in your browser using chrome.storage.sync:

  • Grouping rules you create (keyword patterns and labels)
  • Per-repository rule profiles you configure

This data is synced by Chrome across your own signed-in devices as part of Chrome's built-in sync mechanism. It is never read, accessed, or processed by us.

Permissions used

  • storage — to save and load your grouping rules and profiles.
  • tabs — to read the URL of the active tab so the settings page can pre-fill the current repository when creating a per-repo profile. No tab content is read or stored.

Third-party services

The extension does not integrate with, load code from, or communicate with any third-party service.

Changes to this policy

If the extension's data handling ever changes, this page will be updated and the date above will reflect the revision.
